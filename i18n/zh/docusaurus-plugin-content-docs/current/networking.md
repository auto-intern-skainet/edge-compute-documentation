# 网络架构

Edge-Compute 旨在为 **PoE 供电的测量设备**（Auto-Intern skAInet 产品，但不限于此）提供一个本地计算节点，用于：

- 缓存并预处理数据
- 运行触发器与简单分析
- 将汇聚后的数据流式传输或上传到任意以太网层级结构中的上层

## 以太网布局

设备配备 **2 个以太网接口**：

- **WAN**（`eth1`）：DHCP 客户端，单个 M12 以太网连接器
- **LAN**（`eth0`）：DHCP 服务器，内部连接至 8 端口交换机

## LAN 端口

设备提供 **7 个外部 M12 LAN 连接器**，每个连接器均提供：

- 符合标准的**以太网供电（PoE）**
- 数据连接

因此，只需**一根 Cat-5e M12 以太网线缆**即可连接 skAInet 测量设备。
