# skAInet Edge-Compute

**德国 Auto-Intern GmbH 出品**

![已连接 M12 线缆的 skAInet Edge-Compute](/img/edge-in-use-2.jpg)

**skAInet Edge-Compute** 是一款面向工业边缘应用的可编程 M12-PoE 交换机、路由器与计算模块——一台内置于阳极氧化铝外壳中的坚固计算节点。

- **防水、抗冲击**设计
- 通过 M12 电源连接器以 **48–72 V DC** 供电
- 所有端口及背板均采用 M12 连接器全密封，可在**最高 1 bar 的水下环境中运行**

Edge-Compute 为 **PoE 供电的测量设备**（Auto-Intern skAInet 产品，但不限于此）提供一个本地计算节点，用于：

- 缓存并预处理数据
- 运行触发器与简单分析
- 将汇聚后的数据流式传输或上传到任意以太网层级结构中的上层

查看为 Edge-Compute 打造的 [PoE 测量设备](/devices)——功率、温度、数字 I/O、IO-Link、阻抗谱、红外与信号指示。
